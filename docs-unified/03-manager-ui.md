# 03. UI менеджера проектов (`/`)

> Сводный индекс: [../docs-unified/README.md](./README.md) · API:
> [02-workspace-api](./02-workspace-api.md) · Архитектура: [01-architecture](./01-architecture.md)

Менеджер — новое небольшое React SPA в `app/src` (сборка `app/dist`, раздаётся на
корне :4080). Единственный экран + модальные окна. Стиль — тот же, что у editor и
viewer3d: системный шрифт, панели с заголовком `<h2>`, компактные кнопки, баннеры
ошибок; все строки — в `app/src/i18n/ru.ts`.

## 1. Раскладка экрана

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ Space Manager · проекты                                    [＋ Создать проект]   │
│                                          [⬆ Импортировать из архива…]           │
├──────────────────────────────────────────────────────────────────────────────────┤
│ ┌─ demo-project ────────────────────────┐  ┌─ other ─────────────────────────┐  │
│ │ изменён: 13.09.2026 13:15             │  │ …                               │  │
│ │ файлов: 5 · результатов: 3 · 47 КБ    │  │                                 │  │
│ │ [✎] [🗑]                               │  │                                 │  │
│ │ [Редактор] [Viewer3D] [⬇ Архив]       │  │                                 │  │
│ │ Превью: [▣][▣]  (миниатюры preview/)   │  │                                 │  │
│ └───────────────────────────────────────┘  └─────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────────┘
[баннер ошибок API — красная полоса под шапкой, при сетевых ошибках]
```

- Карточки — адаптивная сетка `repeat(auto-fill, minmax(340px, 1fr))`; порядок — как в
  `GET /api/projects` (`updatedAt` desc).
- Пустой workspace: блок «Проектов пока нет. Создайте первый проект или импортируйте
  архив.» с двумя кнопками действий.
- Данные карточки берутся из списка (§2 API): имя, `updatedAt` (формат
  `DD.MM.YYYY HH:mm` локального времени), число файлов (`files` = filesCount — см.
  примечание 1), `resultsCount`, суммарный размер (КБ/МБ).

Примечание 1: для «числа файлов» используется `GET /api/projects/<p>/files` по
ленивой подгрузке карточки (или поле `filesCount` в списке — **решение**: добавить
`filesCount` в ответ `GET /api/projects`, правка [02](./02-workspace-api.md) §6.2 при
реализации; до этого карточка показывает «—»).

## 2. Действия (связка с API)

| Действие | UI | API | Поведение и состояния |
|---|---|---|---|
| Создание проекта | кнопка в шапке → inline-форма: поле имени + [Создать] / [Отмена] | `POST /api/projects` | Валидация slug ДО отправки (regex §3.1 [02](./02-workspace-api.md)): inline-ошибка «Допустимые символы: a–z, 0–9, `_`, `-`; длина 1–40». 409 → «Проект с таким именем уже существует». Успех → карточка появляется (перезапрос списка), форма скрывается |
| Переименование | `✎` на карточке → модалка: поле нового имени + [Сохранить] / [Отмена] | `PATCH …/rename` | Та же валидация; 409/404 — баннер с текстом API; успех → обновление карточки |
| Удаление | `🗑` на карточке → модалка подтверждения: «Удалить проект «x» и все его файлы? Действие необратимо.» [Удалить] (красная) / [Отмена] | `DELETE …/<p>` | 204 → карточка исчезает; ошибка → баннер. Двойной клик по кнопке невозможен (кнопка блокируется на время запроса) |
| Импорт из архива | кнопка в шапке → скрытый `<input type=file accept=".zip,application/zip">` + состояние «Импортируем…» | `POST /api/projects/import` (ArrayBuffer файла, query `?name=` не передаётся — имя выводится сервером) | Успех → информационный баннер «Проект «<имя>» импортирован: N файлов (пропущено: M)»; 400 `BAD_ZIP` → красный баннер с текстом API. Файл > 10 МБ — клиентская проверка ДО отправки с тем же текстом |
| Открыть редактор | кнопка [Редактор] на карточке | — (навигация) | `location.href = '/editor?project=<name>'` (новый UI открывается в той же вкладке; ссылка `<a href>`) |
| Открыть viewer3d | кнопка [Viewer3D] | — | `/viewer3d?project=<name>` (+ `&result=<latestResult>` если `latestResult` не null) |
| Скачать архив | кнопка [⬇ Архив] | `GET …/archive` | Реализация: `<a href="/api/projects/<p>/archive">` (браузер скачает сам по Content-Disposition). Если генерация в процессе у пользователя в редакторе — ограничений нет (архив снимает текущее состояние) |

## 3. Галерея предпросмотров (preview)

- На карточке блок «Превью»: строка миниатюр (высота 64 px, `object-fit: contain`,
  фон `#f2f4f7`), src = `/api/projects/<p>/preview?file=<name>`. Лимит показа — 8
  последних; при большем числе — счётчик «+N».
- Миниатюры подгружаются лениво (`loading="lazy"`); порядок — как в
  `GET …/previews` (новые первыми).
- **Клик по миниатюре** → модальное окно: картинка в оригинальном качестве (тот же
  URL, без масштабирования ниже фактического размера), под ней имя файла и дата;
  закрытие: крестик, клик по фону, `Esc`. Во время показа модалки скролл страницы
  блокируется.
- Проекты без preview — блок не рендерится (не «Превью: нет»).

## 4. Обработка ошибок и пустых состояний

| Ситуация | UI |
|---|---|
| `GET /api/projects` упал (сервер API недоступен) | Баннер «Не удалось загрузить список проектов: <текст>. Проверьте, что запущен сервис (:4080).» + кнопка [Повторить] |
| Ошибка отдельного действия | Красный баннер под шапкой с `message` из API; автоскрытие через 10 с |
| Проект в списке, но его каталог удалён вручную (404 при действии) | Баннер с текстом API + [Обновить] (перезапрос списка) |
| Проект `corrupted: true` ([02](./02-workspace-api.md) §2) | Карточка с пометкой «⚠ метаданные повреждены»; действия кроме [🗑] неактивны |

## 6. Навигация и URL

- Менеджер — корень `/`; в карточках ссылки на `/editor?project=…` и
  `/viewer3d?project=…` (форматы параметров зафиксированы в [04](./04-integrations.md) §2.5/§3.5).
- В шапках editor/viewer3d появляется кнопка «← К проектам» (`href="/"`) — часть
  адаптаций ([04](./04-integrations.md)).
