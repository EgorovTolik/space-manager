# 04. Правила размещения и принципы соседства

> Сводный индекс: [../README.md](../README.md) · Формат входа: [03-placement-spec.md](./03-placement-spec.md)

## 1. Режим связности и «соседства»

- Текущий срез: **8-окрестность** (`connectivity: 8`).
- Окрестность ячейки `(x, y)` — 8 точек: ортогональные (4) + диагонали (4).
- Связность одного кластера определяется в этой окрестности.
- «Соприкосновение» двух разных кластеров тоже считается по 8-окрестности:
  если ячейки из *разных* экземпляров лежат в 8-окрестности друг друга — они
  **граничат**, и на эту пару типов действует правило соседства.

## 2. Соседство (adjacency) — модель default-open + blacklist

Главное решение: **по умолчанию разрешены любые соседства**, кроме явно запрещённых.

Правило проверки для двух граничащих ячеек из *разных* экземпляров типов `A` и `B`:

1. Если `A == B` → всегда разрешено (однотипные кластеры могут касаться, слияния нет).
2. Иначе, если задан **`allow`** (жёсткий whitelist) → разрешено только если
   `{A, B}` входит в `allow`. Пары из `forbidden` всё равно запрещены.
3. Иначе (default-open, `allow: null`) → разрешено, кроме случаев, когда
   `{A, B}` входит в **`forbidden`**.

Пары типов неупорядоченные: `{A, B} == {B, A}` (симметрично).

Пример: при `forbidden: [[ROOM, WALL]]` и `allow: null`:
- ROOM↔CORRIDOR — ок; CORRIDOR↔WALL — ок; ROOM↔WALL — **нарушение**.

> Почему так выбрано: пользователь явно попросил «если whitelist не задан —
> допускаются любые соседства, кроме blacklist». Это безопаснее с точки зрения
> простоты конфига (перечислять надо только редкие запреты).

## 3. Ограничения на размер (`size`)

- `min`/`max` — **жёсткие** границы числа клеток одного кластера; по умолчанию `null`.
- Если заданы, нарушение = невозможность размещения (hard fail).
- Если не заданы, то кластер **может получиться меньше или больше** расчётного
  целевого размера (цель мягкая — см. [05](./05-solver-design.md) §2); при недостаче
  система обязана предупредить пользователя.

## 4. Форма (`shape`)

Ограничение формы кластера, задаётся в `clusters[].shape`:

- **free** — любая связная форма (проверяется только связность по 8-окрестности).
- **rectangle** — область должна быть сплошным осевым прямоугольником `w × h`
  без выемок и «дыр». Валидация: клетки кластера = ровно все клетки его
  bounding-box, и bounding-box заполнен целиком.
- **circle** — приближение диска: существует целочисленный центр `(cx, cy)` и радиус
  `R`, так что клетки кластера ≈ { (x,y) : max-ish расстояние ≤ R }. Допускается
  небольшое отклонение по границе (пиксельный диск не идеален). Точная метрика —
  в [05-solver-design.md](./05-solver-design.md) §4.

## 5. Выпуклость (`convexity`)

- Текущий срез: **мягкое предпочтение** (`weight: soft`).
- Метрика (дешёвый прокси, выбрана нами): **заполненность bounding-box**:
  `fill_ratio = area(cluster) / area(bounding_box(cluster))`. Чем ближе к 1 — тем
  форма «выпуклее»/ровнее.
- Использование: при выборе среди равнодопустимых позиций кластера солвер
  предпочитает кандидата с бо́льшим `fill_ratio` (штраф в целевой функции).
  Это **не** жёсткий запрет вогнутых форм.
- `weight: hard` (запрет вогнутых) — не реализовано в текущем срезе, зарезервировано.

## 6. Заполнение площади (`fillAll`)

- `false` (по умолчанию): кластеры размещаются «как можно ближе» к своим долям;
  свободные клетки могут остаться пустыми.
- `true`: система стремится использовать всю доступную площадь F; «лишнее»
  пространство распределяется **пропорционально** долям кластеров (не сваливается
  в один кластер).

## 7. Заблокированные зоны и предзаполнение

- Блокировки (`*`): клетка никогда не получает кластер; исключается из базы F.
- Preset-кластеры: неподвижны, другие кластеры не могут их перекрывать или «вкладывать» в себя.
  На текущем срезе вкладывания нет вообще — preset просто занимает клетки.

## 8. Сводка жёстких и мягких условий

| Условие | Тип | Источник |
|---|---|---|
| Связность каждого кластера (8) | жёсткое | rules.connectivity |
| Соблюдение формы, если задана (rect/circle) | жёсткое | clusters[].shape |
| Не ставить в блокировки / preset | жёсткое | blockedFile / presetFile |
| Запрет пар из `forbidden` (и whitelist `allow`, если задан) | жёсткое | rules.adjacency |
| Жёсткие `size.min/max` (если заданы) | жёсткое | rules.size |
| Приближение к долям площади | мягкое | clusters[].areaPercent |
| Выпуклость формы | мягкое (soft) | rules.convexity |
