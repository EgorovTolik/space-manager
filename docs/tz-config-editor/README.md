# ТЗ: Веб-редактор конфигураций space-manager

Редактор с веб-интерфейсом для работы с файлами проекта `space-manager`:
спеками размещения (YAML), масками заблокированных клеток и пресетами предзаполнения.

## Ключевые решения (согласованные с заказчиком)

1. **Стек**: React + Vite + TypeScript + Express.
2. **Работа с файлами: «загрузил → отредактировал → скачал обратно».** Сервер не имеет доступа к диску проекта; файлы живут в состоянии приложения, экспорт — скачиванием.
3. Редактор обязан **полностью модифицировать** спеку и **создавать новые** файлы с нуля.
4. Модель: одна спека связана с 0/1 маской и 0/1 пресетом; визуальные редакторы работают в рамках `grid` спеки; есть сценарий «создать комплект с нуля».
5. Палитра типов для пресета: из спеки **или создаётся на лету** прямо в редакторе.
6. Случайная/быстрая генерация раскраски **не нужна** — её выполняет сам `space-manager`.
7. Блокировки файлов, многопользовательский режим, аутентификация — **не нужны**.
