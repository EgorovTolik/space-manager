# 2. Форматы файлов

Формальные описания трёх типов файлов, с которыми работает редактор. Источники правды: `docs/03-placement-spec.md`, `docs/04-rules-and-adjacency.md` и примеры в `examples/` проекта `space-manager`.

## 2.1 Спека размещения (`*.yaml`)

```yaml
grid:
  width: 50            # целое > 0
  height: 50           # целое > 0

blockedFile: null      # путь к маске (относительный) или null
presetFile: null       # путь к пресету (относительный) или null

types:                 # словарь: КЛЮЧ → описание типа
  ROOM1:     { symbol: "R", name: "Комната-1" }   # symbol — ОДИН символ, уникален среди типов; не "*" и не "."
  CORRIDOR:  { symbol: "C", name: "Коридор" }

rules:
  connectivity: 8      # связность для размещаемости кластера (4 или 8)
  adjacency:
    forbidden: []      # список пар типов, которым запрещено примыкать; пустой список = default-open
    allow: null        # белый список пар или null (= любые пары разрешены)
  size:
    min: null          # мин. размер кластера (клеток) или null
    max: null          # макс. размер кластера (клеток) или null
  convexity:
    weight: soft       # вес ограничения выпуклости: soft | hard
  fillAll: false       # заполнить всю доступную площадь
  touchAll: false      # все кластеры обязаны примыкать друг к другу

clusters:              # список целей размещения (порядок — значим в выводе, менять можно)
  - id: room1          # уникальные идентификаторы внутри спеки
    type: ROOM1        # должен ссылаться на ключ из types
    areaPercent: 26    # доля от доступной площади F, число (0..100]; сумма по всем кластерам ≤ 100
    shape: free        # free | rectangle | circle
```

**Правила спецификации:**
- `areaPercent` кластера превращается решателем в цель `round(F · areaPercent / 100)`;
- `shape = circle` — кластер должен получиться «круглым», `rectangle` — прямоугольным, `free` — без требования к форме;
- комментарии (`# …`) допустимы; редактор при экспорте **не обязан** сохранять исходные комментарии (допуск: выдавать чистый YAML), но ключи и структуру — обязан сохранить.

## 2.2 Маска заблокированных клеток (`blocked_*.txt`)

Текстовый файл ровно `width` × `height` строк/символов (без пробелов и пустых строк внутри):

| Символ | Значение |
|---|---|
| `*` | клетка заблокирована (недоступна для размещения) |
| `.` | клетка свободна |

```
**........      ← строка = 10 символов, всего 10 строк для grid 10×10
**........
..........
...
```

**Требования к файлу:** ровно `height` строк по `width` символов; символы только `*` и `.`. Размеры обязаны совпадать с `grid` связывающей спеки.

## 2.3 Пресет предзаполнения (`preset_*.txt`)

Текстовый файл того же размера, что маска:

| Символ | Значение |
|---|---|
| `.` | клетка не задана (решатель размещает свободно) |
| один из `symbol` типов спеки | клетка заранее занята этим типом |

```
..AAAA....      ← A — symbol типа; BBB — другой тип
..AAAA....
..........
BBB.......
...
```

**Требования:** размеры = `grid` спеки; все символы, кроме `.`, должны существовать в `types` связывающей спеки (иначе решатель не сможет расшифровать файл).

## 2.4 Связи и целостность комплекта

```
spec.yaml ──blockedFile──▶ blocked_*.txt   (опционально)
          └──presetFile───▶ preset_*.txt    (опционально)
```

- Маска/пресет **не содержат** ссылок обратно на спеку — связь односторонняя, из YAML.
- В редакторе комплект считается состоящим из трёх связанных сущностей; пути в `blockedFile`/`presetFile` при экспорте сохраняются как заданы (редактор не переименовывает файлы без явного действия пользователя).

## 2.5 Ограничения, контролируемые редактором (сводка)

| # | Проверка | Уровень |
|---|---|---|
| V1 | `grid.width`, `grid.height` — целые > 0 | ошибка |
| V2 | ключи `types` уникальны и непустые; `symbol` — ровно один символ, не `*`, не `.`, уникален в пределах `types`; `name` непустой | ошибка |
| V3 | `clusters[].id` уникальны и непустые | ошибка |
| V4 | `clusters[].type` ∈ ключи `types` | ошибка |
| V5 | `clusters[].areaPercent` — число в (0..100] | ошибка |
| V6 | сумма `areaPercent` ≤ 100 | предупреждение* |
| V7 | `shape` ∈ {free, rectangle, circle} | ошибка |
| V8 | размеры маски/пресета = `grid` спеки | ошибка |
| V9 | маска содержит только `*` и `.` | ошибка |
| V10 | все символы пресета (кроме `.`) ∈ `symbol` типов | ошибка |
| V11 | `blockedFile`/`presetFile` указаны, но соответствующий файл в комплекте отсутствует | предупреждение |

\* В примерах проектов сумма долей может превышать 100 при `fillAll: false`, если пользователь сознательно переразмет — оставляем **предупреждением**, не блокируем экспорт. Решатель примет финальное решение.
