# 4. Дизайн интерфейса

## 4.1 Экраны и компоновка

Одностраничное приложение (SPA). Один основной экран: **Рабочая область комплекта**.

```
┌──────────────────────────────────────────────────────────────────────┐
│ [Логотип/название] │ Имя спеки (редактируемое)  │ ⚠ N ошибок │ 💾 Скачать ▾ │
├───────────────┬──────────────────────────────────────────────────────┤
│ Боковая панель│                                                        │
│ ───────────── │          ВКЛАДКА СЕТКИ (маска или пресет)              │
│ 📄 Комплект   │  ┌────────────────────────────────────────────┐        │
│   ✓ spec.yaml │  │                                            │        │
│   ✓ blocked…  │  │            ВИЗУАЛЬНАЯ СЕТКА W×H           │        │
│   ○ preset…   │  │         (кисть/ластик, drag-раскраска)     │        │
│ ───────────── │  │                                            │        │
│ 📐 Сетка      │  └────────────────────────────────────────────┘        │
│ 🎨 Типы       │  Панель инструментов: [кисть][ластик] [размер ▾]      │
│ ⬛ Кластеры    │  Для маски: [очистить всё][заблокировать всё]  F = 96 │
│ ⚙ Правила     │  Для пресета: палитра типов ● R Комната ● C Коридор   │
│ ───────────── │                                                        │
│ ⚠ Валидация   │                                                        │
└───────────────┴──────────────────────────────────────────────────────┘
```

- **Вкладки сетки**: «Маска» / «Пресет» — переключение визуального редактора (если файла нет во вкладке — кнопка «создать/загрузить»).
- **Боковая панель** — навигация по разделам спеки: при клике правая часть показывает либо форму раздела (Сетка/Типы/Кластеры/Правила), либо сетку. Альтернатива (допустима): формы разделов — слева ниже панели, сетка всегда видна справа. Решение на усмотрение реализации при условии, что **сетка и активный раздел видны одновременно**.

## 4.2 Сценарии пользователя

### С1. Открыть и поправить существующую спеку
1. «Открыть» → выбрать `spec.yaml` (+ маски/пресет, если есть ссылки).
2. Вкладка «Маска»: дорисовать заблокированные клетки.
3. Раздел «Кластеры»: изменить `areaPercent`.
4. Проверить панель валидации (0 ошибок) → «Скачать» три файла.

### С2. Создать комплект с нуля
1. «Новый комплект» → задать 50×50.
2. Раздел «Типы»: добавить ROOM/R, CORRIDOR/C.
3. Вкладка «Пресет»: раскрасить стартовые зоны.
4. Раздел «Кластеры»: добавить цели с долями и формами.
5. Назвать файлы в диалоге экспорта → скачать.

### С3. Доработать только пресет
1. Загрузить `preset_example.txt` без спеки → временная палитра из символов A/B.
2. Дополнить палитру новыми типами на лету, докрасить сетку.
3. «Скачать комплект»: приложение создаёт спеку с этими типами + размеры из пресета и выгружает все три файла.

## 4.3 Компоненты (минимальный набор)

| Компонент | Назначение |
|---|---|
| `Dropzone` | Загрузка файлов (drag&drop + выбор), определение типа по содержимому/расширению |
| `SpecForm` (Grid / Types / Clusters / Rules) | Формы разделов спеки с локальными валидациями инпутов |
| `PixelGrid` | Универсальная сетка W×H: пропс-функция «клетка → стиль», события paint/erase; отрисовка — CSS Grid или Canvas (решение в 05) |
| `MaskTools` / `PresetTools` | Панели инструментов и палитра для каждого режима |
| `PaletteEditor` | Список типов-кистей: цвет, символ, имя; создание на лету |
| `ValidationPanel` | Ошибки/предупреждения с якорями на разделы |
| `ExportDialog` | Имена файлов + кнопки скачивания (каждый файл и «все») |
| `NewSetDialog` | Диалог создания нового комплекта (width, height) |

## 4.4 Правила UX

1. **Никаких необратимых действий без подтверждения**: удаление типа/кластера, смена размера сетки — подтверждение или undo-доступность.
2. Все валидационные сообщения — на русском, указывают конкретное поле/клетку.
3. Счётчики (F, занятость по типам, N ошибок) обновляются мгновенно при каждом действии.
4. Кнопка «Скачать» визуально блокируется при наличии ошибок (с тултипом-списком).
5. Пустые состояния: нет комплекта — центральный экран с кнопками «Открыть» / «Создать новый».

## 4.5 Ключевые ограничения UI

- Размеры сетки для отрисовки — до 200×200 клеток; ниже — автоподбор размера клетки (FR-12).
- Минимальная рабочая ширина окна — 1024 px.
