# 07. Нефункциональные требования и ограничения

> Сводный индекс: [../docs-editor/README.md](./README.md) · Тестирование:
> [06-testing-acceptance](./06-testing-acceptance.md)

## 1. Целевая платформа (вводные №4, №6)

| Параметр | Требование |
|---|---|
| Платформа | десктоп (персональный ПК), локальный запуск; минимальное окно браузера 1280×768 |
| Браузеры | современные Chrome / Firefox / Safari (последние два стабильных мажорных релиза); мобильные браузеры — не поддерживаются |
| Язык UI | русский (единственный; строки вынесены в `src/i18n/ru.ts`) |
| Пользователи | один, локально; auth/multiuser вне v1, архитектура их не исключает ([03-api-express](./03-api-express.md) §5) |
| Сеть | редактор работает полностью офлайн после запуска (все данные — в браузере и на диске пользователя); внешних сервисов/CDN нет |

## 2. Сохранность данных

- Всё состояние — в памяти браузера (React state). **Refresh / закрытие вкладки =
  потеря несохранённых изменений.** Обязательный `beforeunload`-диалог при dirty-состоянии
  ([04-ui-ux](./04-ui-ux.md) §8).
- Единственный способ перенести данные — скачать файлы. Сервер ничего не хранит
  (вводная №3); local persistence (localStorage/IndexedDB) в v1 **не** используется —
  осознанное решение против усложнения; на roadmap (§5).

## 3. Производительность (детализация [06](./06-testing-acceptance.md) §6)

| Ограничение | Значение | Обоснование |
|---|---|---|
| Максимальный размер сетки в UI | **200×200** (40 000 клеток); создание спеки с бо́льшими W/H допускается, но при загрузке маски > 200×200 UI показывает предупреждение «Сетка очень велика — редактирование может быть медленным» | рендер canvas — только видимые клетки (viewport-crop, [04-ui-ux](./04-ui-ux.md) §3.4), поэтому даже 500×500 технически отображается; порог 200×200 — гарантированный плавный опыт на десктопном ПК среднего уровня |
| FPS панорамирования/зума (≤ 200×200) | ≥ 30 FPS | стандарт интерактивности |
| Отклик на клик | ≤ 100 мс | — |
| Объём prod-бандла SPA | ≤ 500 КБ gzip (первичный) | без тяжёлых зависимостей (решение [01](./01-architecture.md) §2.5); проверка в CI |

## 4. Известные ограничения v1 (зафиксированы, не считаются дефектами)

1. **Комментарии YAML не сохраняются** при скачивании спеки: сериализация — из
   структурной модели ([02](./02-data-model-formats.md) §4). Пользователь предупреждается
   UI при первом скачивании изменённой спеки. Маски комментариев не имеют — там
   round-trip побайтовый (каноническая форма, [02](./02-data-model-formats.md) §5).
2. **Нет генерации размещения** — редактор только готовит входные файлы (вводная №2).
3. **Нет undo/redo**, нет версии файлов на сервере, нет автосохранения (§2).
4. `connectivity` и `convexity.weight` в UI — read-only (текущий срез системы: 8 / soft;
   docs/03 §1, docs/04 §5); загруженные значения round-trip'ятся как есть.
5. Перетаскивание строк кластеров (порядок) — drag&drop не реализовано; порядок =
   порядок добавления.
6. Маска блокировок и preset-карта редактируются **поочерёдно** в двух режимах одной
   области (§3.1 04-ui-ux); одновременного «двойного» canvas'а нет.

## 5. Roadmap (вне v1, не блокирует приёмку)

| Пункт | Примечание |
|---|---|
| Undo/Redo в сессии | стек действий over `EditorState` |
| Автосохранение состояния в IndexedDB | восстановление после refresh |
| Серверная проверка спеки через `space_manager` (опциональный эндпоинт) | точный арбитр ошибок парсинга Python-системы ([03-api-express](./03-api-express.md) §5) |
| Auth/мультиюзер, сетевой режим | вводная №4 — «архитектура не должна исключать» |
| Экспорт превью маски в PNG/SVG | отладочный инструмент |
| Drag&drop порядка кластеров, зум-пресеты | UX-улучшения |

## 6. Требования к коду (для разработки)

- TypeScript `strict: true`; без `any` в публичных сигнатурах `lib/`.
- Чистые модули `lib/*` не импортируют React — только типы модели и js-yaml.
- ESLint + Prettier; лимит сложности (cyclomatic) функций ≤ 10.
- Все строки UI — в `i18n/ru.ts` (никаких hard-coded строк в компонентах).
- CI: `tsc --noEmit`, `eslint`, unit (Vitest), e2e (Playwright, Chromium), сборка +
  проверка размера бандла.
