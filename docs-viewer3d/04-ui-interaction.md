# 04. UI и взаимодействие

> Сводный индекс: [README.md](./README.md) · Состояние/actions: [01-architecture](./01-architecture.md) §2.3–§2.7 ·
> Геометрия (цвета, размеры): [03-wall-geometry](./03-wall-geometry.md) §8–§9

Язык интерфейса — **русский** (единственный). Платформа — десктоп; минимальный целевой
размер окна браузера **1280×768**; вёрстка плотная, трёхколоночная (CSS без UI-фреймворка,
как в `editor/`).

До загрузки файла: в центре — заглушка «Загрузите файл отчёта (result-*.txt)»; панели
«Параметры» и правая колонка неактивны (серые, tooltip «Сначала загрузите отчёт»).

## 2. Панель «Файл» (`FilePanel`)

- Кнопка «📂 Загрузить отчёт…» → `<input type=file accept=".txt,text/plain">` +
  drag&drop в область панели. Чтение — `FileReader.readAsText(file, 'utf-8')`.
- Статус после загрузки: имя файла (basename), размер сетки `W×H`, число комнат; при
  `infeasible` — красная пометка «размещение не удалось» (полный текст — баннер §9).
- Повторная загрузка заменяет состояние полностью (`REPORT_LOADED`); подтверждение не
  требуется (неизменяемых данных нет).
- Ошибки парсинга (`ReportParseError`, коды V-* из [02](./02-input-parser.md) §5.1):
  баннер с первым кодом/сообщением + полный список в раскрывающемся списке; сцена не
  строится, правые панели неактивны.

## 3. Панель «Параметры» (`ParamsPanel`)

| Параметр (название в UI) | Поле `ViewParams` | Дефолт | Диапазон | Шаг | Примечание |
|---|---|---|---|---|---|
| Масштаб, ед./клетка | `scale` (S) | `1` | 0.1 … 50 | 0.1 | мировые единицы на клетку (README §3 п.3) |
| Высота стены | `wallHeight` (Hw) | `3` | 0.1 … 20 | 0.1 | одинакова для всех стен (вводная №2) |
| Толщина стены | `wallThickness` (T) | `0.25` | 0.05 … 2 | 0.05 | умеренная толщина, не линия (вводная №2) |
| Единица | `unitLabel` | `м` | текст ≤ 10 символов | — | произвольная подпись единицы; площадь показывается как `<n> <unitLabel>²` |
| Показывать blocked | `showBlocked` | `true` | чекбокс | — | тёмные блоки по клеткам `*` (03 §8) |
| Прозрачность стен | `wallsOpacity` | `1.0` | 0 … 1 | 0.05 | слайдер; при < 1 материал transparent |
| Скрыть стены | `hideWalls` | `false` | чекбокс | — | полное скрытие (режим «вид сверху»); при включении слайдер прозрачности неактивен (значение сохраняется) |
| Подписи комнат | `showLabels` | `true` | чекбокс | — | см. §8 |

Кнопка **«Сбросить параметры»** → все дефолты таблицы выше (`RESET_PARAMS`).

Поведение: числовые поля принимают только значения из диапазона (вне — приводятся к
границе); пересчёт геометрии стен при смене S/T — debounce **200 мс** (03 §10); Hw и
оптические параметры не требуют пересчёта XZ-геометрии.

## 4. 3D-сцена (`Scene`)

### 4.1 Canvas и рендеринг

`<Canvas gl={{ preserveDrawingBuffer: true, antialias: true }}>` (preserveDrawingBuffer
обязателен для PNG-снапшота, §10). Фон `#f2f4f7`, свет — по [03](./03-wall-geometry.md) §9.
Контент сцены: `BasePlate`, `RoomFloor` на каждую комнату, `Walls` (один InstancedMesh),
`BlockedBoxes` (один InstancedMesh, скрыт при `showBlocked=false`), `RoomLabels`,
`OrbitControls`.

### 4.2 OrbitControls

- вращение — ЛКМ-drag; панорама — ПКМ-drag; зум — колесо (стандартное поведение drei);
- демпфирование включено (`enableDamping`);
- целевая точка по умолчанию — центр сетки на половине высоты стен `(0, Hw/2, 0)`;
- без ограничения «под пол»: `maxPolarAngle = π` (видеть можно со всех сторон — вводная №5).

### 4.3 Нормализованное расстояние камеры

Обозначим `D = max(W, H) · S · 0.9`. Все пресеты и фокус (§5) используют D/размеры
комнаты в мировых единицах.

### 4.4 Пресеты видов (кнопки тулбара + клавиши 1/2/3)

| Пресет | Клавиша | Позиция камеры | Целевая точка |
|---|---|---|---|
| Изометрия | `1` | `(D, 0.9·D, D)` | `(0, Hw/2, 0)` |
| Сверху | `2` | `(0, D, 0.001·D)` | `(0, Hw/2, 0)` |
| Спереди | `3` | `(0, Hw/2, D)` | `(0, Hw/2, 0)` |

У пресета «Сверху» добавлен смещение `0.001·D` по Z — иначе вектор up камеры
вырождается и OrbitControls «залипает»; после пресета орбита работает как обычно.
Применение пресета — мгновенное (без анимации; анимации — roadmap v2,
[05](./05-testing-acceptance.md) §8). Начальный вид при загрузке файла — «Изометрия».

### 4.5 Строка статуса (под canvas)

`{W}×{H} клеток · S = {scale} {unitLabel}/клетку · комнат: {N} · стен: {M} боксов`.

## 5. Список комнат (`RoomsPanel`)

Таблица, одна строка на комнату (порядок — растровый, как в `ParsedReport.rooms`):

| Колонка | Содержимое |
|---|---|
| метка | `room.label` (id из таблицы или автоимя, [02](./02-input-parser.md) §6.4); при выделении — жирным/подсветкой строки |
| символ | цветной чип (квадрат 12×12 px цвета палитры [02](./02-input-parser.md) §8) + символ |
| тип | `room.typeId` из сопоставленной строки таблицы; «—», если не сопоставлена |
| клеток | `room.size` (целое) |
| площадь | `size · S²`, 2 знака, + ` {unitLabel}²` |
| статус | `tableRow.status` («ок»/«недостача»/«превышение»); «—», если строка не сопоставлена |

**Клик по строке** → действие `SELECT_ROOM` + **фокус камеры на комнате**:

```
target'  = ( (centroid.x − W/2)·S , Hw/2 , (centroid.y − H/2)·S )        # центр комнаты
dir      = normalize(camera.position − target)                          # текущее направление взгляда
dist     = max(bboxW, bboxH) · S · 1.6 + Hw                             # bbox в клетках: x1−x0+1, y1−y0+1
camera.position = target' + dir · dist;  controls.target = target'
```

(мгновенно, без анимации). Повторный клик по выделенной строке — снимает выделение.

Под таблицей — блок **«В таблице, но не найдено на карте»** (строки `unmatchedRows`):
`id — type, факт N кл.`; для `actual = 0` добавляется «(не размещён)». Блок пустой — не
рисуется. Ниже — **легенда** (`Legend`): чип цвета + символ + type_id (если известен) —
порядок палитры ([02](./02-input-parser.md) §8).

## 6. Карточка выбранной комнаты (`InfoPanel`)

Показывается при `selection ≠ null`:

```
room1
символ R · тип ROOM1
клеток: 650 · площадь: 650 м²
габариты (bbox): 25 × 26 м
— строка таблицы (если сопоставлена):
  доля 26% · цель 650 · факт 650 · отклонение 0 · статус ок
[Снять выделение]
```

«Габариты» = `(x1−x0+1)·S × (y1−y0+1)·S` с подписью единицы. Для комнат без строки
таблицы блок «строка таблицы» не показывается; тип — «—».

## 7. Выбор комнаты кликом в 3D

- клик ЛКМ по полу комнаты (raycast по mesh'ам `RoomFloor`, R3F `onClick` +
  `event.stopPropagation()`) → `SELECT_ROOM(index)`;
- клик по базовой плите / пустому месту сцены → снять выделение (`selection = null`);
- **hover**: курсор меняется на pointer (onPointerOver/Out) — подсветка при наведении
  в v1 не делается (только курсор);
- **выделение**: у выбранной комнаты материал пола получает emissive-подсветку
  (тот же цвет, intensity 0.25) + подсветка строки в списке (§5). Стены выделению НЕ
  подсвечиваются — они общие для соседних комнат (ограничение v1, [05](./05-testing-acceptance.md) §8).

## 8. Подписи комнат на сцене (`RoomLabels`)

- `drei <Html>` в мировой позиции `(cx, Hw·0.5, cz)` центра комнаты (cx/cz — из
  `centroid`, формулы [03](./03-wall-geometry.md) §1);
- текст = `room.label`; `pointerEvents: none` (не перехватывают клики), без occlusion
  (видны сквозь стены — ограничение v1, упрощение);
- подписи рисуются только для комнат с `size ≥ LABEL_MIN_CELLS = 4` (фиксированная
  константа — мелкие комнаты засоряют сцену; их метки видны в списке §5) и при
  `showLabels = true`.

## 9. Баннер предупреждений (`WarningsBanner`)

Расположен над canvas, рисуется только когда есть что показать:

1. `infeasible = true` → **красный** баннер с текстом блока «НЕ УДАЛОСЬ…» дословно
   (`infeasibleText`, [02](./02-input-parser.md) §1.4);
2. далее — список (жёлтый фон) всех `issues` уровня warning (W-*, 02 §5.2) по одной
   строке на код+сообщение;
3. далее — строки секции «ПРЕДУПРЕЖДЕНИЯ» отчёта (`warningsSection`) как есть.

Блок прокручиваемый, max-height 120 px; сворачивается кнопкой «Свернуть» (счётчик
остается видим). При отсутствии файла/ошибок — не рисуется.

## 10. Экспорт снапшота PNG (кнопка в тулбаре)

- Иконка «PNG» активна, только когда отчёт загружен и сцена построена;
- механизм: `gl.domElement.toBlob(cb, 'image/png')` (работает благодаря
  `preserveDrawingBuffer: true`, §4.1) → Blob → `<a download>`;
- имя файла: `viewer3d-snapshot-<YYYYmmdd-HHMMSS>.png` — тот же формат timestamp, что у
  CLI-отчётов (`cli.py::default_result_name`);
- снимается **только canvas сцены** (без DOM-панелей).

## 11. Строки интерфейса (i18n)

Все строки UI — в одном модуле `src/i18n/ru.ts`: именованные константы + функции
шаблонов для строк с подстановками (например, статус сетки, площадь). Внешних i18n-
библиотек нет; русский — единственный язык (README §4). Запрещено дублировать строки
по компонентам.

## 12. Клавиатура

| Клавиша | Действие |
|---|---|
| `1` / `2` / `3` | пресеты видов: изометрия / сверху / спереди (§4.4) |
| `Esc` | снять выделение комнаты |

Горячие клавиши игнорируются, когда фокус в текстовом поле (проверка
`document.activeElement`). Прочих горячих клавиш в v1 нет.
